Chapter 1: DSPy メンタルモデル & 思考のパラダイムシフト

従来の「プロンプトエンジニアリング」から DSPy への最大の転換点は、PyTorch と同じメンタルモデルを持つこと です。

💡 黄金律: 開発者とアルゴリズムの役割分担 開発者は「入出力の型 (Signature)」と「処理ロジック (Module)」だけをコードで定義します。
「どんな指示文にするか」や「どんなFew-Shot例を埋め込むか」は Optimizer（アルゴリズム）に完全委譲 します。
開発要素 PyTorch (機械学習) DSPy (LLMプログラミング) 担当
タスク契約 Tensor Shape dspy.Signature (input ➔ output) 🧑‍💻 開発者
処理構造 nn.Module dspy.Module (Predict, CoT等) 🧑‍💻 開発者
評価基準 Loss Function (損失関数) Metric (EM, LLM-as-a-Judge) 🧑‍💻 開発者
最適化対象 モデルの重み (Weights) 指示文 (Instruction) & Few-Shot (Demos) 🤖 Optimizer

Chapter 2: 入出力設計 (Signature) & モジュール構築 (Module)

タスクの入出力仕様を宣言的に定義し、推論モジュールを組み立てます。

import dspy

class ExpenseApprovalSignature(dspy.Signature):
    """提出された経費申請内容を審査し、承認(approved)または否認(rejected)を判定する。"""

    expense_details: str = dspy.InputField(desc="経費申請の詳細（品目、金額、理由等）")
    approval_status: str = dspy.OutputField(desc="approved または rejected")
モジュール 特徴 適用ユースケース
dspy.Predict 直接入力を出力に変換。思考トークンなし。 単純分類、短い定型変換 (最速・最安)
dspy.ChainOfThought reasoning フィールドを前挿入して推論。 論理的推論、審査、複合判定 (+5〜15% 精度向上)
dspy.ReAct Thought ➔ Action ➔ Observation ループ。 Web検索やツール実行を伴うAgent

Chapter 3: 評価関数 (Metric) エンジニアリング & trace 引数

DSPy の評価関数は、学習時と評価時で二重の役割を持ちます。

Metric 呼び出し ├── trace is not None (学習時) ➔ 損失関数モード (部分点 0.0〜1.0 を返し探索勾配を作る) └── trace is None (評価時) ➔ 評価指標モード (厳格な判定 1.0 or 0.0 を返す) 
def robust_metric(example, pred, trace=None) -> float:
    gold = getattr(example, "expected_status", "").strip().lower()
    predicted = getattr(pred, "approval_status", "").strip().lower()
    is_exact = (gold == predicted)

    if trace is not None:
        # 学習時は部分点を与えてOptimizerの探索を促す
        if is_exact:
            return 1.0
        elif gold in predicted:
            return 0.5
        return 0.0

    return 1.0 if is_exact else 0.0

課題 2: 部分一致を考慮した損失関数（Metric）を実装せよ 
def triage_metric(example, pred, trace=None) -> float:
    urgency_match = (getattr(pred, "urgency", "").lower() == getattr(example, "expected_urgency", "").lower())
    dept_match = (getattr(pred, "department", "").lower() == getattr(example, "expected_dept", "").lower())

    if urgency_match and dept_match:
        return 1.0

    if trace is not None:
        return 0.5 if (urgency_match or dept_match) else 0.0

    return 0.0
